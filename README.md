# HoloPrism 🔮

> **Holographic greeting cards by Mason** — Replace paper cards with a magical transparent pyramid experience.

---

## What is HoloPrism?

HoloPrism is a mobile app + physical transparent pyramid device that creates a "magical moment" where holographic animations appear to float inside the pyramid when placed on your phone screen.

## Features

- 🚀 **Animated Hologram Templates** — Rocket, Balloon, Firework Heart
- 🎨 **Full Customization** — Text, media upload, voice messages, animation styles
- 📱 **4-Way Hologram Format** — Auto-mirrored display for the pyramid optics
- 🔮 **AR Preview Mode** — Simulate the hologram in space
- 📦 **Order System** — Choose prism size, shipping, checkout
- 🎬 **Social Sharing** — TikTok, Instagram, Snapchat

## Tech Stack

- React 18 + Vite 8
- Pure CSS animations (no external UI library)
- Mobile-first design (430px)
- SVG cartoon animations

## Getting Started

```bash
npm install
npm run dev
```
